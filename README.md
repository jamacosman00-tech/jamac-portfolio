# Jama Osman — Personal Portfolio

A responsive personal portfolio website built with **React, Vite, JavaScript, and Tailwind CSS**.

The portfolio presents my education, technical skills, projects, certificates, achievements, and learning journey as a Computer Science student.

## ✨ Features

- Responsive portfolio layout for desktop and mobile
- React component-based architecture
- Project showcase with detailed project information
- Certificates section with PDF access
- Education and learning journey timelines
- Skills and achievements sections
- Responsive navigation
- Contact section
- Modern dark developer-focused UI

## 🛠️ Tech Stack

- React
- Vite
- JavaScript (ES Modules)
- Tailwind CSS
- Lucide React
- ESLint

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Vite will display the local development URL in the terminal.

### 4. Build for production

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```

## 📌 Notes

- `node_modules/` and `dist/` are excluded from Git through `.gitignore`.
- No API keys or environment secrets are required by this frontend project.
- Certificate and CV files included in the portfolio are intentionally part of the project. Review them before making the repository public if you do not want those documents publicly accessible.
